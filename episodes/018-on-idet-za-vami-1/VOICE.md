# Озвучка: «Он идёт за вами», часть 1

Fish Audio → голос **«Опытный Диктор»** (или AI Studio → голос **Charon**).
Текст — `voice_text.txt` целиком.

Стиль (для AI Studio — в Style instructions; в Fish — просто читать ровно):
```
Напряжённый рассказ-предупреждение от второго лица. Низкий ровный голос, близко к микрофону — БЕЗ шёпота, без придыхания, без актёрства.
Темп быстрый и плотный, короткие паузы — ролик должен уложиться в 50–55 секунд.
Первая фраза — чётко, с нажимом на «ни в коем случае не идите домой».
«А лица всё равно не видно.» — медленнее, пауза после.
«Четыре. Семь.» — два отдельных слова, пауза между ними.
«Гудок. Второй.» — с паузами.
«А потом трубку снимают.» — тихо и твёрдо, но не шёпотом.
```

Файл — `assets/voice.wav` (или пришли mp3 — переконвертирую).
