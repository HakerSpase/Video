# Озвучка: «Зимовье»

Google AI Studio → Generate speech → Single-speaker → голос **Charon** (мужской, низкий).
Текст — `voice_text.txt` целиком. Если не влезает — две половины: до «Я не ответил.» и с него; пришли оба файла.

Style instructions:
```
Мужчина рассказывает реальную историю, которая случилась с ним самим. Он до сих пор напуган, но держится.
Голос низкий, тихий, близко к микрофону, как рассказ ночью у костра. Без актёрства, без «страшного» голоса.
Темп медленный. После каждого короткого предложения — пауза.
«Шаг. Пауза. Шаг.» — очень медленно, почти шёпотом, с длинными паузами между словами.
Слова за дверью («Лёха, открой. Это я, Серёга. Я замёрз», «Лёха. Открой.») — тише, ровно, без интонации, чуть растягивая «Лёха».
«Мама умерла три года назад» — ровно, после этого пауза две секунды.
Запись из тетради — медленно, сухо, как читают чужой почерк.
«Обратно в лес следов не было» — после этого пауза.
Время на снимках («Два четырнадцать…») — отдельно, с паузой после каждого.
«Снимок сделан изнутри зимовья» — тихо, на выдохе. Пауза две секунды.
Последняя фраза «Если это, конечно, будет Серёга» — очень тихо и медленно.
```

Файл — `assets/voice.wav` (WAV или MP3 — без разницы).
